# APO-MOVE-005 — 7-Day Monolith Sprint Plan

**Date locked:** 2026-04-14 UTC  
**Owner:** Gaia  
**Project:** monolith  
**Task:** APO-MOVE-005  
**Window:** 2026-04-14 → 2026-04-20 UTC

## Why this exists

Monolith progress has been too incremental and too maintenance-shaped.

The lane has produced real artifacts, but too much of the visible activity has been:
- doc rewiring
- shared-path syncing
- restoration of missing artifact surfaces
- one-card-at-a-time primitive expansion

That is motion, not enough throughput.

This sprint shifts APO-MOVE from a background trickle lane into a **batched research + synthesis lane**.

## Sprint goal

By the end of 7 days, Monolith should have materially more usable strategic raw material, not just cleaner folders.

## Hard success criteria

By end of sprint, deliver **all** of the following:

### 1) Four new full target packets
Complete and move to review:
1. `shared/docs/targets/alcoholics-anonymous.target-packet.md`
2. `shared/docs/targets/scientology.target-packet.md`
3. `shared/docs/targets/qanon.target-packet.md`
4. `shared/docs/targets/burning-man.target-packet.md`

Minimum bar per packet:
- glossary >= 30 terms with sources
- representative protocol / participation map
- pull-factor matrix
- mechanism notes
- Section G mitigations / safe-translation notes where needed

### 2) Eight new or upgraded synthesis cards
Create or substantially upgrade **8** durable synthesis artifacts/cards under:
- `shared/docs/targets/primitives/`
- and/or the core synthesis docs if the change is materially new

These count only if they add real analytical substance, not path cleanup.

### 3) One new cross-case comparison artifact
Create **one** new synthesis document that compares the enlarged corpus across movement types.

Target artifact:
- `shared/docs/targets/movement-comparison-matrix-v1.md`

Required lens:
- healthy vs dark
- in-person vs digital-native
- premium vs mass-access
- missionary / evangelism capacity
- operator-production capacity
- decay / abuse risk

### 4) One executive synthesis memo for Loki
Create:
- `shared/state/gaia/mission-control/deliverables/APO-MOVE-005-weekly-synthesis-2026-04-20.md`

This memo must answer:
- what mechanics now look universal
- what mechanics are subtype-specific
- what appears most reusable
- what appears most dangerous
- what Monolith should likely borrow later
- what still needs research next

## What does NOT count as progress

The following do **not** count toward sprint success by themselves:
- README rewiring
- path sync / canonical copy restore
- artifact relocation
- fixing references to files that already exist conceptually
- re-reporting prior work in new checkpoint docs

Those are hygiene tasks, not sprint wins.

## Operating rules for this sprint

1. **Batch, don’t trickle.**
   - A work block should end with a packet or a real synthesis artifact.
   - Avoid one-note heartbeats like “added a little more.”

2. **Research first, synthesis second, hygiene last.**
   - Artifact cleanup only after substantive output lands.

3. **Use shared canonical paths immediately.**
   - Write directly to `shared/docs/targets/...` whenever possible.

4. **No blueprint drift.**
   - This remains movement-DNA research for Monolith input later.
   - It is not live movement design.

5. **Progress is quota-based.**
   - The lane is judged by completed packets and synthesis outputs.
