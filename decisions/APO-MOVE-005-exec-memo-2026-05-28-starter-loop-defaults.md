## Purpose

## Recommended defaults

### 1) First-session visible win
**Default:** return one personalized **Clarity Card** at the end of onboarding.

The card should contain:
- one named pattern or friction point
- one leverage insight in plain English
- one specific next move for the next 24 hours

Why this default:
- it makes the product feel intelligent fast
- it fits Apotheosis's cognitive-mapping promise
- it is emotionally useful without feeling mystical or overbuilt

### 2) Saved artifact
**Default:** save the Clarity Card as a **Day 0 Snapshot** in the user's timeline/home surface.

Minimum fields:
- title
- one-sentence insight
- one next action
- timestamp

Why this default:
- it leaves proof that something happened
- it gives the user a durable reference point
- it creates an obvious comparison object for Day 1 and Day 7 returns

### 3) Next-day ritual mode
**Default:** make the repeat action **session-driven first**, with optional reminder hooks added later only if the in-session loop works.

Ritual shape:
- 2-minute check-in
- ask whether yesterday's next move happened
- update the card with one small progress trace or revised next move

Why this default:
- safest, least spammy starting point
- tests the ritual itself before testing notification strategy
- avoids mistaking push performance for product value

## Acceptance criteria for v0
A new user should be able to:
1. finish onboarding
2. receive one Clarity Card before leaving
3. find that card again later
4. complete the next-day check-in in under 2 minutes
