# Movement Lexicon & Naming-Pattern Log (language-system DNA ledger)

> **Status note — 2026-03-15:** older versions of this file drifted toward naming our own movement. That is no longer the canonical scope of this file. Monolith is the downstream movement Loki is building, but this document exists to track cross-case naming systems, vocabulary compression patterns, role labels, and phrase mechanics across movements as part of the movement-DNA research program.

Goal: capture how successful movements use names, titles, metaphors, compressed vocabulary, mottos, and phrase structures so the patterns can be compared across the database and later mined for inspiration when adding language systems, role labels, slogans, and framing into Monolith.

How to use:
- Append observations from real targets, not invented brand names for Monolith.
- Track recurring structures: identity labels, rank names, ritual verbs, enemy/problem words, slogan shapes, sacred-object names.
- If a pattern seems useful for Monolith later, note **why** it works — do not turn the file into direct Monolith drafting.
- Cluster later into comparative themes (identity, rituals, ranks, verbs, symbols, missionary language, in-group/out-group language).

## Cross-case naming-pattern observations

### Identity label patterns
- transformation / upgrade labels
- practitioner / initiate / graduate labels
- insider / elite / chosen labels
- operator / leader / guide / coach labels

### Rank / ladder label patterns
- numbered stages
- color systems
- titles / honorifics
- certification labels
- inner-circle labels

### Ritual / action verb patterns
- words for joining
- words for confessing / declaring
- words for serving / recruiting
- words for leveling up
- words for enduring / proving / completing

### Enemy / problem words
- what the movement says is broken
- what keeps people stuck
- what must be escaped / transcended / defeated

### Promise / destiny words
- freedom
- truth
- mastery
- awakening
- power
- discipline
- belonging
- mission
