| Code | Meaning |
|---|---|
| **S** | Strong / load-bearing rite in that packet. Named as a durable engine in the §5 table and/or exec / extracted-primitives list. |

## 6. Why-it-works map

Coverage before cleverness. Each type: what the rite is doing mechanically when it is **S**, then strongest anchors, then leftovers that lack it or invert it. Not instructions. Not how to run a rite.

When it is **S**, the first crossing installs a memory that “I am in.” The body or the wallet or the name changes in one sitting.
