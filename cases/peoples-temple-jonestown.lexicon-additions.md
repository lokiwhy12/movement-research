## Identity labels
- **Temple member / Peoples Temple** — base belonging noun
- **Father / Dad / Jim** — founder address terms (adults and children)
- **Marceline** — wife/manager proper name used as soft authority
- **Rainbow family** — interracial household/congregation destiny label
- **Apostolic socialist / socialist** — late identity replacing plain Christian
- **Pioneer** — early Guyana settler honorific
- **Staff** — inner-circle operators (often white, college-educated women)
- **Troops** — outsider nickname for majority-Black rank-and-file workers
- **Planning Commission** — governing identity/board
- **Red Brigade** — armed security identity (Guyana accounts)
- **Concerned Relative** — external counter-identity (defector families)
- **Traitor / Trotskyite defector / Coca-Cola revolutionary** — Jones labels for leavers (Gang of Eight era)
- **Jonestown resident** — enclosed commune identity
- **Survivor** — post-1978 residual identity (media/scholarship)

## Rank / ladder labels
- visitor / aid recipient → offering member → communal resident / care-home client → bus worker → Planning Commission → staff/inner circle → security/Red Brigade → Father apex
- **Mother church (Redwood Valley)** vs urban temples (SF/LA) as geographic rank
- **Georgetown assignment** vs **Jonestown field** as soft status (better food/proximity rumors)
- **White Night veteran / Six-Day Siege** as ordeal rank
- **Disciples of Christ affiliation** as external respectability rank (not internal belt)
- Financial rank = how completely assets/income were surrendered
- Posthumous “rank” only via archive citation / memorial plaque — no living hierarchy

The headline: **Father proximity + asset surrender + White Night compliance** did more ranking work than formal degrees.
