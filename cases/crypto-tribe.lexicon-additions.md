## Identity labels

- Bitcoiner — default in-group noun (interpreter; conference/Magazine). Official bitcoin.org says "Bitcoin users."
- HODLer — Magazine 2021: not the same as a mere holder; conviction identity. Origin: Bitcointalk GameKyuubi Dec. 18, 2013.
- orange-pilled — Ledger glossary / Magazine: Matrix-colored convert. Official bitcoin.org pages opened this pass do not use it.
- nocoiner — outsider who holds none (Magazine "get off zero"; Lopp).
- shitcoiner — holder of other tokens; purity insult (Lopp). Official scams page says "scam coins," not this slur.
- pleb / gigachad — Magazine HODL caste jokes.
- maximalist / toxic maximalist — Vitalik 2014 pejorative, later reclaimed (Lopp).
- node runner / full-node operator — official vocabulary; verification identity.
- whale — conference pass name and market slang (Wikipedia via CNBC-style explainers not opened; conference.b.tc opened).
- cypherpunk — Lopp closing; Wikipedia origin layer. Not a bitcoin.org rank.

- weak hands / day traders (Bitcointalk)
- FUD (Magazine HODL)
- Bitcoin Jonah / skeptics / journalists (Rochard)
