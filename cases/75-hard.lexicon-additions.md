## Identity labels
- **75 HARD** — the program-name that is also the identity (“I’m doing 75 HARD”)
- **Day X** — the portable self (“I’m on Day 47”)
- **finisher** — post-Day-75 self; unofficial but structurally implied
- **someone who does what they said** — official after-state
- **passenger-seat person** — official before-state
- **mentally tough** — the trait-as-identity the program claims to install
- **zero-compromise person** — doctrine as character
- **LIVEHARD** — year-self, not a 75-day tourist
- **Phase 1 / Phase 2 / Phase 3** — ladder nouns that become calendar identity
- **restarter** — the shame-and-pride hybrid after a miss
- **modifier** — unofficial out-group; official: you cheated

---

## Rank / ladder labels
- lurker → Day 1 → Day X → Day 75 → Phase 1 → (30-day off) → Phase 2 → Phase 3 / year
- **Day count** is the everyday rank. There is no sash.
- **restart to Day 1** is a demotion that the doctrine treats as integrity, not failure-of-character *if* you actually restart — and as cheating if you don’t
- **LIVEHARD year** is the ascension rank
- **annual repeater** — official perishable-skills rank
- merch / patch as optional visible rank (hub)
- no certified-coach rank on pages opened

The existing log line (“discipline language that turns compliance into identity”) is the headline. The addition is that **the number is the name**; rank is a streak, not a title.
