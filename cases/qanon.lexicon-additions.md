## Identity labels

- **Anon / anons** — rank-and-file poster (Wikipedia)
- **Baker** — interpreter who assembles crumbs into “bread” (Wikipedia)
- **Digital soldier / patriot** — participant-as-combatant (Flynn phrase adopted; Wikipedia; NBC)
- **Q / Q Clearance Patriot** — claimed oracle identity, not a verified person (Wikipedia; ADL)
- **White hat / black hat** — in-group / enemy sorting (ADL; Frontiers)
- **Autists** — chan-board compliment for obsessive connection-making (ADL; slur-adjacent; in-group only)
- **Normie / sheeple / asleep** — out-group (Wikipedia)
- **Pastel QAnon** — wellness/Instagram-aesthetic adherent class (Wikipedia citing Argentino)
- **Fence sitter / true believer / activist / apostate** — Pierre typology via Frontiers
- **Protzmanian** — named splinter around Michael Protzman (ADL)
- **American State National** — sovereign-citizen-adjacent self-label used by some Q-adjacent (ADL)

## Rank / ladder labels

- lurker / fence sitter → anon / researcher / baker → digital soldier → group admin / rally organizer → influencer-clergy → merch-app-book operator → candidate / conference speaker
- **Rx-equivalent is not a QAnon word.** Rank is **decode-hours, channel size, merch, proximity to Trump-amplification, tripcode mystique**
- Q is not a membership tier; it is an **oracle slot** (contested authorship)
- Official Team-equivalent is **interpreter clergy** (YouTube/Telegram) vs street-rally “Save the Children” public face
- Apostate / r/QAnonCasualties / r/ReQovery is the exit identity (Wikipedia)

The missing log line is that **the slogan is both a belonging badge and a wearable SKU**: WWG1WGA functions as motto, merch, and in-group password.
